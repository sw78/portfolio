00O aplikacji

Aplikacja powstała we współpracy Szymona Wolniewicza z AI.

Wykorzystane biblioteki: Mermaid.js (generowanie diagramów UML), SheetJS / xlsx.js (eksport do Excela), mark.js (podświetlanie dopasowań w tekście). Dopasowywanie fuzzy (odległość Levenshteina) i pozostała logika analizy działają lokalnie w przeglądarce, bez użycia zewnętrznego API.

Generator SQL: na podstawie Słownika Encji (sekcja 04) aplikacja proponuje instrukcje CREATE TABLE dla MySQL, PostgreSQL lub SQL Server — z kluczem głównym id, typami kolumn dobranymi na podstawie nazw atrybutów oraz kluczami obcymi dla wykrytych powiązań między encjami.

06Generowanie SQL (DDL)

Na podstawie Słownika Encji (sekcja 04) silnik proponuje typy kolumn na podstawie nazw atrybutów (np. „Imię" → VARCHAR(100), „Cena" → DECIMAL(10,2), „Data..." → DATETIME), dodaje klucz główny id oraz klucze obce dla wykrytych powiązań między encjami. To sugestia robocza — zawsze zweryfikuj przed wdrożeniem.

-- Kliknij "Generuj SQL", aby zbudować CREATE TABLE na podstawie Słownika Encji.

07Raport dla Zarządu

Wygeneruj czytelny, sformatowany raport podsumowujący całą analizę — gotowy do przedstawienia zarządowi lub klientowi. Otworzy się w nowej karcie; stamtąd zapisz go jako PDF (Ctrl+P / Cmd+P → "Zapisz jako PDF"). Jeśli w sekcji 05 wygenerowano diagramy UML lub w sekcji 06 schemat SQL, zostaną dołączone automatycznie.
